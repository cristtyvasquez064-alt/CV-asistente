# Carpeta de Imágenes para el CV

Aquí puedes guardar tus imágenes personalizadas para tu Currículum Vitae.

### 1. Logo de la barra de navegación:
* **Archivo por defecto:** `img/logo.svg`
* **Para usar tu propio logo:** Guarda tu imagen aquí (por ejemplo `img/logo.png`) y actualiza el archivo `index.html` en la sección `<!-- Brand logo -->`.

### 2. Foto de perfil:
* **Archivo por defecto:** `img/perfil.svg`
* **Para usar tu foto:** Guarda tu foto aquí (por ejemplo `img/foto.jpg` o `img/perfil.png`) y actualiza el archivo `index.html` en la sección `<!-- Avatar/initials card -->`.

### Formatos recomendados:
* `.jpg` / `.jpeg`: Excelente para fotografías reales.
* `.png`: Excelente para imágenes con fondo transparente.
* `.svg`: Ideal para logos vectoriales que nunca pierden calidad.
* `.webp`: Formato moderno de alta compresión y excelente calidad.
